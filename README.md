# study-pinn

研究生学习计划实验仓库：**传统数值计算 · PDE 求解 · 优化算法 → 物理信息神经网络（PINNs）**

从可验证的传统数值算法出发，逐步建立 PDE 离散、稳定性分析、误差评估与数值优化能力，
最终以同一 PDE 为基准比较传统数值方法与 PINN。

## 目录结构

| 目录 | 内容 |
|------|------|
| `week01_error/` | 数值微分与数值积分的误差分析（差分截断误差、误差随 h 先降后升） |

> 后续按 `weekNN_主题/` 逐步补充：数值线性代数、非线性方程、椭圆/抛物/双曲型 PDE、
> 有限体积、有限元、谱方法、优化算法（GD/Adam/Newton/BFGS/LM）、PINN 基线等。

## 环境

- Python 3.8+
- 依赖：`numpy`、`matplotlib`（部分实验还需 `scipy` / `torch`）

## 误差指标约定

- 离散相对 L2 误差：`E2 = ‖u_num − u_ref‖2 / ‖u_ref‖2`
- 最大误差：`E∞ = max|u_num − u_ref|`
- 实验收敛阶：`p = log(E_h / E_{h/2}) / log 2`
